# ? GUIA RÁPIDO - INÍCIO IMEDIATO

## ?? PASSO A PASSO

### 1?? INSTALAR PACOTE SVG (OBRIGATÓRIO!)

**Opção A - Via Visual Studio (Mais Fácil):**
1. Abra a solução no Visual Studio
2. Clique com botão direito no projeto "ConversorSvgToPng"
3. Selecione "Manage NuGet Packages"
4. Clique em "Browse"
5. Procure: **Svg**
6. Clique "Install" no pacote "Svg"
7. Aceite as licenças

**Opção B - Via Console:**
```
Tools > NuGet Package Manager > Package Manager Console
```
Digite:
```powershell
Install-Package Svg
```

### 2?? COMPILAR

1. Pressione **F6** ou vá em **Build > Build Solution**
2. Aguarde a compilação terminar
3. Verifique se não há erros

### 3?? EXECUTAR

1. Pressione **F5** ou clique em **Start**
2. A aplicação abrirá!

### 4?? USAR

1. **Arraste ficheiros SVG** para a área indicada
2. **Configure o tamanho** (ex: 512x512)
3. Clique em **?? Converter**
4. Pronto! Ficheiros na pasta "Convertidos"

## ?? PROBLEMAS COMUNS

### ? Erro: "O tipo Svg não pôde ser encontrado"
**Solução:** Instale o pacote NuGet "Svg" (Passo 1)

### ? Aplicação não inicia
**Solução:** Compile novamente (F6) e verifique erros

### ? Ficheiros não convertem
**Solução:** Verifique se os SVG são válidos
